Codex CLI 0.167.0 在 2026 年 11 月 6 日更新，新增了可选手动开启 macOS 或 Windows 系统代理，适合走公司代理的环境。已经连上的后端之间切换时，草稿会保留。这个版本还加了未读结果标记和本地图片预览，安装时需要指定 0.167.0。

## 要点

- 0.167 可在 /experimental 启用 macOS 或 Windows 系统代理。
- 已连接后端之间切换时，草稿会保留。
- 顺带有未读结果标记与本地图片预览；用 npm 装指定 0.167.0。
