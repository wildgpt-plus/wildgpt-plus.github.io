用不完的 OpenAI API 额度，并不能当成代金券转手卖掉或送人；个人 API Key 也不是兑换码。官方的服务积分条款和使用政策都写了：积分不可转让，Key 不要共享，否则可能影响账号。这篇文章把积分、密钥和正常应用接入的界线说清楚，方便团队用对方法协作。

## 要点

- 适用服务积分条款的额度不应出售、赠送或交易。
- 不要共享个人 API Key；团队协作使用成员与项目权限。
- ChatGPT 订阅和 API 计费相互独立，正常开发应遵守适用限制。
