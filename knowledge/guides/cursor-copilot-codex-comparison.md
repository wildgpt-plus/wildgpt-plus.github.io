这三样不是互斥的同一个开关。先看你主要在哪写代码、账单要记在哪，再决定用编辑器自带能力、Copilot，还是再装官方 Codex 扩展。

## 要点

- Cursor 是带 Agent 的编辑器，按它自己的订阅计费；Copilot 主要嵌在 GitHub 和常用 IDE 里，按 GitHub 的套餐和 AI credits 计费；Codex 是 OpenAI 的编程代理，可用 ChatGPT 套餐或 API Key。
- 已经在用 Cursor 时，仍可再装官方 Codex 扩展：它和 Cursor 自带的 Chat、Agent、Tab 是分开的，也不依赖 Cursor 模型选择器里是否还有 OpenAI 模型。
- 价格和包含用量以各产品官方定价页为准，本文只转述 2026-11-19 核对过的套餐档位，不做未核实的效果对比。
