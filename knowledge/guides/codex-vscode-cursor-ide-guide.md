在 VS Code 或 Cursor 里装官方 Codex 扩展，打开侧边栏后登录，就可以对着当前项目开始改代码。登录方式和计费路径不要混用。

## 要点

- 在 VS Code 或 Cursor 的扩展市场安装官方 Codex 扩展（openai.chatgpt），然后打开 Codex 侧边栏。
- 日常写代码优先用 Sign in with ChatGPT，用量走套餐额度；Use API Key 会按 API 平台价格计费，开不了 Codex Cloud。
- 这个扩展和 Cursor 自带的 Chat、Agent、Tab 是分开的：装了 Codex，并不会自动改写 Cursor 原来的模型选择。
