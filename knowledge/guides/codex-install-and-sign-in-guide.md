先选入口，再安装，最后登录。日常写代码优先用 ChatGPT 账号登录，把 API Key 留给自动化任务。

## 要点

- Codex 随 ChatGPT 套餐提供，Free 和 Go 也能用本地 Codex；Codex Cloud 向符合条件的 Plus 及更高套餐开放，受开放进度与工作区设置影响；Free 和 Go 不包括。
- CLI 可用官方安装脚本、npm 或 Homebrew；编辑器里装 Codex 扩展，用命令面板打开侧边栏，再用 ChatGPT 账号登录。
- 启动时报 approval_policy untrusted，按官方说明删掉这个过时配置即可，它已经不再被支持。
