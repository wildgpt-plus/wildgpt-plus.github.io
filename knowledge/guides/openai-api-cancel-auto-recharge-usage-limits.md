停的是开发者账单里的自动买额度，不是 ChatGPT 会员的取消按钮。两本账要分开看。

## 要点

- 不想让 API 自动扣款买额度，首次开通时关掉 Use auto-reload；之后可调整阈值和每月自动充值上限，或取消 API 计费计划以关闭自动充值，剩余额度仍能用。
- 真正控预算要靠组织或项目的硬性花费上限；每月自动充值上限只限制自动购买，不限制已有额度怎么用。
- 取消 ChatGPT 订阅不会自动关掉 API。付费功能可用到当前周期结束；API 和用 API Key 的 Codex 仍按 API 账单走，已发放的订阅 API 额度可用到过期。
