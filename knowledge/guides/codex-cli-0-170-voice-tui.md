这版最显眼的是终端里能语音通话。CLI 版本和当前会话都支持语音时，输入 /voice 或按 F8 即可。

## 要点

- 0.170.0 为终端界面的实时语音通话加入了 WebRTC 协商；在 CLI 版本和当前会话都支持语音时，可用 /voice 或 F8 开始和结束通话。
- 另外还有 OpenTelemetry HTTP 导出器的认证头自动刷新，以及实验性的跨环境同名 MCP 服务器支持。
- 修复集中在连接回退、Cloud 重连、Windows 与沙箱权限，以及文件和线程搜索；升级后用 codex --version 确认版本。
