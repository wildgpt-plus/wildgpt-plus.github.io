先别急着换说法硬试。官方建议收窄范围、只保留说明结果所必需的上下文，并把 AGENTS.md 保持精简。

## 要点

- ChatGPT、Codex 和 API 可能对部分网络安全或生物相关请求做额外检查，内容无法显示并不等于已经被判定违规。
- 先把任务收窄到防御、修复或分析的目标，只保留必要上下文；改几个词再试，官方写明并不会因此改变请求是否被允许。
- AGENTS.md 应保持精简，合并后默认上限是 32 KiB；不要把任务进度写进这份规则文件，过长先删回到项目约定，再开新会话。
