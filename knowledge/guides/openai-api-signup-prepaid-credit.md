这是 API 平台的预付费额度，不是 ChatGPT 会员订阅。先看官方能不能开通，再决定怎么加额。

## 要点

- 开通 API 要在 API 平台添加付款信息并购买预付费额度，最低 5 美元，默认 10 美元；这和 ChatGPT 订阅是两本账。
- 已购买额度通常一年后过期；预付卡不能买 API 额度，银行卡须由支持地区的银行发行。
- 官方支持名单目前不含中国大陆、香港和澳门。能完成官方加额后，再去创建 API Key，并把自动充值和花费上限设好。
