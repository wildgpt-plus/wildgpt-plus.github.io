这是 API 平台的预付费额度，不是 ChatGPT 会员订阅。先看官方能不能开通，再决定怎么加额。

## 要点

- 想获取 OpenAI API Key，要先在 API 平台添加付款信息并购买预付费额度，最低 5 美元，默认 10 美元；这和 ChatGPT 订阅是两本账。
- 完整密钥只在创建时显示一次，请立刻保存；不要共享个人 Key，团队应邀请成员并按权限和过期策略轮换密钥。
- 已购买额度通常一年后过期；预付卡不能买 API 额度，银行卡须由支持地区的银行发行。官方支持名单目前不含中国大陆、香港和澳门。
