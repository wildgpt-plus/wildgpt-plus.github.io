MCP 让 Codex 能查文档、看日志、操作浏览器。配一次，CLI、桌面版和 IDE 插件都能用。

## 要点

- 最快的加法是一条命令：codex mcp add 名称 -- 启动命令；HTTP 服务器用 --url。
- 配置写在 ~/.codex/config.toml，ChatGPT 桌面版、Codex CLI 和 IDE 插件共用，配一次三处都能用。
- 用 enabled_tools、disabled_tools 和 approval_mode 控制能调哪些工具、要不要先问你。
