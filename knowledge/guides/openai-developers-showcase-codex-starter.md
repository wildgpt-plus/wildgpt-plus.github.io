OpenAI Developers 插件新增了 Showcase 标签，里面是已经能跑起来的 API 示例项目。多数项目可以在 Codex 里打开，再按你的需求改，而不用从零写。示例会调用 API，费用和 ChatGPT 订阅是分开的；符合条件的 Pro 或 Business 可以领取 API 额度。

## 要点

- Showcase 是 OpenAI Developers 插件里的新标签，放的是能直接跑的 API 示例项目。
- 多数项目支持 Open in Codex，打开后让 Codex 按你的需求改。
- 示例跑起来要调 API，费用和 ChatGPT 订阅分开算；符合条件的 Pro / Business 可领 API 额度。
