两款新产品都要申请，门槛不低。真正马上能用的，是在 GitHub PR 里评论一句 @codex security review。

## 要点

- Daybreak Red Team 做 Web 应用渗透测试，Defense Factory 扫 GitHub 仓库并准备补丁，两者都要先拿到 Daybreak 权限。
- Pro、Business、Enterprise、Edu 现在就能在 GitHub PR 里用 @codex security review，Plus 不支持。
- 想在本地或 CI 里扫代码，可以用 Codex Security 插件和开源的 codex-security CLI。
