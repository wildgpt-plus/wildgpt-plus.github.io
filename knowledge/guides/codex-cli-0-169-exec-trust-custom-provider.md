Codex CLI 0.169.0 已在北京时间 11 月 13 日下午发布。这次最要紧的变化是：在还没信任过的目录里，codex exec 不会加载项目配置和 MCP 服务器，自动化脚本需要加上 --trust。终端里也可以直接添加自定义模型供应商，没有浏览器的远程服务器还能用设备码登录。

## 要点

- codex exec 在未信任目录里不会加载项目配置和 MCP 服务器，脚本要用 --trust 明确信任。
- 终端里可以直接加自定义模型供应商，远程服务器没浏览器也能用设备码登录网关。
- 侧边对话标签、旧任务搜索、折叠过程、本地保存诊断包等体验改进一并上线。
