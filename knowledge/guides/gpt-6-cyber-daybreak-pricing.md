GPT-6 Cyber 是面向授权安全研究的模型，走 Daybreak Red 通道，不是 ChatGPT 里随手就能点开的功能。它的 API 定价高于前代，初期只对部分获批客户开放。日常使用 Go 或 Plus 的人，不必为此去申请 Daybreak。

## 要点

- GPT-6 Cyber 面向授权安全研究，走 Daybreak Red，不是 ChatGPT 普通聊天功能。
- API 定价高于前代；初期仅部分获批客户，后续会扩大。
- 日常 Go/Plus 用户不必申请 Daybreak；要 ChatGPT 套餐可看 WildGPT。
