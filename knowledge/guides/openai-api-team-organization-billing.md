团队用 API，账单记在组织上，不要把一把个人密钥发给所有人。先完成官方预付费加额，再邀请成员、分项目并设花费上限。

## 要点

- 团队加额要在 API 组织的 Billing 里完成官方预付费购买，最低 5 美元，默认 10 美元；不要共享一把个人 API Key。
- 有权限的 Owner 可在 People > Members 邀请同事，角色选 Owner 或 Reader，并至少加入 1 个项目。
- 预付卡不能买 API 额度，支持名单目前不含中国大陆、香港和澳门；花费上限和自动充值要单独设置。
